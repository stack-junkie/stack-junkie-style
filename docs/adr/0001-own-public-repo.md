# Stack Junkie Style lives in its own public GitHub repo

Stack Junkie Style grew from a skill into a product: web and native libraries, a showcase, shared tokens, versioning and packaging. So it moves out of the Agent Skills repo into its own public repo on GitHub (`stack-junkie/stack-junkie-style`), keeping its git history. Agent Skills keeps only a pointer to it, so the skill stays installable. The new and old web and native versions are swapped before the move, so the new repo starts on the final version. Decided by Chris on 2026-11-26.
