# Look-alike apps are exempt from the system's look

Every project with a front end uses Stack Junkie Style by default, except a look-alike app: one built to deliberately imitate an existing app, like SJ Paint imitating Microsoft Paint. A look-alike follows the imitated app's look and layout, and may still use the library's pieces where they fit. Without this record, a future agent would "fix" SJ Paint into the App frame. Decided by Chris on 2026-11-26.
