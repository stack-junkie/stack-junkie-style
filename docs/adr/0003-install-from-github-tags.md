# Projects install the library from tagged GitHub releases

Projects install Stack Junkie Style straight from a tagged release in its public GitHub repo: web projects as a git dependency pinned to the tag, native projects through CMake fetching the tag. Publishing to the public npm registry was the alternative. It was deferred because it adds a public release step, and every project is Chris's own. It can be added later with his approval. Decided by Chris on 2026-11-26.
